# ⚽ US College Soccer Recruiting Hub (アメリカ大学サッカー部 リクルート管理アプリ)

アメリカの大学サッカー部（NCAA Division 1/2/3, NAIA, NJCAA/短大）への**編入（大学2年次修了後 → 3年次編入）**・スカウト獲得を目指す日本人選手・保護者・指導者のための総合リクルート支援Webアプリケーションです。収録大学は374校（男子サッカー部のみ）です。

---

## 🌟 主な機能一覧

### 1. 選手プロフィール & 公式スカウトレジュメ作成 (Athlete Profile & Scout Sheet)
- **個人情報・基本スペック**: 氏名（日/英）、編入希望時期（例: Fall 2027）、卒業予定年、現在のカテゴリー、取得済み単位数、残り競技年数、ポジション（第1/第2）、利き足、身長/体重、背番号。
- **学業・語学スペック**: 大学GPA（4.0換算）、TOEFL iBT / Duolingo / SATスコア、希望専攻（Major）。
- **NCAA / NAIA Eligibility ID**: 米国大学体育協会登録番号の一元管理。
- **映像リンク**: ハイライト動画（YouTube/Hudl）および公式戦フルマッチ（90分）動画リンク。
- **フィジカル・受賞歴**: 50m走、Yo-Yoテスト数値、全国大会出場歴、県ベストイレブンなど。
- **1クリックPDF出力 / 印刷機能**: 米国カレッジスカウト仕様の英語レジュメシート（Transfer Candidate / Rising Junior、A4 1枚フォーマット）をワンクリックで印刷・PDF保存可能。

### 2. 全米大学サッカー部データベース検索 (College Explorer)
- **NCAA D1 / D2 / D3 / NAIA / NJCAA (JUCO)** の代表校・日本人受け入れ実績校データを網羅。
- **多軸フィルター**: ディビジョン、地域（West, South, Midwest, Northeast）、キーワード検索。
- **詳細情報**: ヘッドコーチ名、コーチ連絡先メール、推定年間学費、寮費、奨学金上限枠、留学生比率、大学公式HP・リクルート質問票URL。
- **カスタム大学追加**: リサーチした任意の大学を自由に追加可能。
- **大学比較**: カードの「比較」ボタンで最大4校を選び、学費・総額・GPA/TOEFL・強豪度などを横並びで比較（各項目の有利な値を緑でハイライト）。
- **財務リスク(破綻の可能性)の目印**: 私立の222校について、米国教育省NCES/IPEDSの公開財務データ(2020-21〜2022-23年度)から、運営収支・純資産の厚み・純資産の3年間の増減・授業料依存度・負債比率を点数化し、「⚠ 注意」(12校)・「⚠ 要注意」(6校)の目印を大学カードに表示します。大学データベース検索の「財務リスク」フィルターで絞り込めます。公立大学・短大(JUCO)はデータ形式が異なるため未評価です。**これは閉校を予測するものではなく、データ上の目安です。最新の状況は大学の公式発表・報道・認証機関の情報で必ず確認してください。**


### 2.5 ダッシュボードのリマインダー
- **期日超過 / 7日以内の次アクション / 14日以上連絡なし**の大学を上部に自動表示。
- 「次のToDo」は期日の近い順に並び、残り日数バッジを表示。選考ステージ別の大学数ファネルも表示。

### 3. リクルート選考カンバンボード (Recruitment CRM)
- **選考ステージ別の進捗管理**:
  1. `Prospect (候補・リサーチ中)`
  2. `Contacted (メール送信済)`
  3. `In Discussion (やり取り・Zoom面談中)`
  4. `ID Camp / Visit (キャンプ参加・キャンパス訪問)`
  5. `Offer Received (オファー獲得 / 奨学金提示)`
  6. `Committed (進学決定)`
  7. `Closed (見送り・不合格)`
- 各大学ごとの「次のアクション（ToDo）」、「期日」、「奨学金提示額」、「コーチのメモ」を記録。

### 4. 英語スカウティングメール自動生成 (Email Pitch Generator)
- 登録した選手プロフィールと対象大学の情報を自動で差し込み、ネイティブコーチに響く英文メールを作成。
- **テンプレート一覧**:
  - `1. 編入希望の初回連絡＆ハイライト映像送付 (Transfer Inquiry & Highlights)`
  - `2. 現シーズンの試合日程・映像更新の案内 (Current Season Schedule & Film Update)`
  - `3. Zoom面談・キャンパス訪問後の御礼とフォロー (Post-Meeting / Visit Follow-up)`
  - `4. 成績・単位・英語スコア更新の連絡 (Academic & Transfer Credit Update)`
  - `5. オファーへの感謝と検討回答 (Offer Gratitude & Discussion)`
- **ワンクリック操作**: クリップボードコピー & メーラー（メールソフト）即時起動。

### 5. 編入ロードマップ & 規定ガイド (Transfer Roadmap & NCAA/NAIA Rules)
- **編入ロードマップ（2年次修了後 → 3年次編入）** のタイムラインとToDoチェックリスト（全21項目）:
  1. Sophomore 前期（現状把握・候補リサーチ・映像更新）
  2. Sophomore 後期（現コーチへの相談・Transfer Portal・コーチへの直接アプローチ）
  3. Summer（オファー比較・編入出願・単位認定）
  4. Junior 入学前（SEVIS Transfer・I-20・渡米・プレシーズン合流）
- 編入規定（Transfer Portal、SEVIS Transfer、Eligibilityなど）は一般的な内容を記載しています。**最新規定はNCAA / NAIA公式サイトで必ず確認してください。**
- **ディビジョン別 奨学金枠比較表（2025/2026年最新ルール対応）**:
  - **NCAA D1**: 【2025/2026〜新制度】ロスター上限28名に対し、大学予算に応じて**最大28名全員へ奨学金支給可能**（従来の男子9.9枠 / 女子14.0枠の上限が撤廃）。
  - **NCAA D2**: 最大9.0枠（分割支給 / 留学生フレンドリー）
  - **NCAA D3**: スポーツ特待なし（手厚い学業奨学金・給付金あり）
  - **NAIA**: 最大12.0枠（フルスカラシップ実績多数）
  - **NJCAA D1**: 最大18.0枠（学費・寮費・食費フルカバー特待）
- **スカウト成功の鉄則 (Do's & Don'ts)**: 映像の作り方、メールの送り方、GPAの重要性。

### 6. 奨学金・自己負担学費シミュレーター (Scholarship Calculator)
- 年間学費、寮費、保険・諸費の入力。
- **スポーツ特待（Athletic Scholarship %）** スライダーによる即時再計算。
- **学業奨学金（Academic Merit Aid）** の合算控除。
- 為替レート（1 USD = 円）連動の自己負担額（万円/年）シミュレーション。編入後2年間（3〜4年次）の概算も表示。

### 7. データ保存・バックアップ
- ブラウザの `LocalStorage` にリアルタイム自動保存。
- **JSON形式でのエクスポート / インポート** に対応（別PCやスマートフォンへのデータ移行も容易）。

## 🔒 個人情報の扱い (GitHubに載せない運用)

- **GitHubに置くもの（共通）**: `index.html` / `app.js` / `data.js` / `styles.css` など。大学データ・テンプレートのみで、個人情報は含みません。
- **個人データの保存先**: プロフィール・管理中の大学(パイプライン)・メモ・ロードマップ進捗は、**各端末のブラウザ(`localStorage`)にのみ**保存されます。サーバーやGitHubへは送信されません。
- `data.js` の初期パイプラインとプロフィールは空です。実データは入っていません。
- **プロフィールのファイル保存**: プロフィール画面の「ファイルに保存」で、プロフィールだけを `US_Soccer_Profile_<名前>_<日付>.json` として書き出せます。キャッシュ削除後や別端末では、「ファイルから読み込む」（起動時の確認画面にも同じボタンあり）で復元できます。
- **端末間の移行（PC → スマホ等）**: プロフィールのみならファイル保存、全データ（選択校・メモ含む）ならサイドバーの「保存」(JSON)→別端末で「復元」。ファイルはクラウド(OneDrive等のプライベート領域)やAirDrop、メール等で渡し、**GitHubには上げない**でください。
- **起動時の確認**: 起動時にプロフィールの有無を確認します。「作成せずに大学を探す」「プロフィールを適用せずに検索」を選ぶと、保存済みプロフィールを消さずに検索・比較だけ使えます（このモード中はプロフィールの保存・書き出しは行われません）。
- `private/` フォルダ、`US_Soccer_Recruiting_Backup_*.json`、`US_Soccer_Profile_*.json` は `.gitignore` で除外済みです（`private/my-recruiting-data.json` は初期の選択校のコピー。インポートで復元できます）。
- **LINEから開くとき**: LINE内蔵ブラウザは通常のブラウザと保存領域が別なので、データが分かれてしまいます。ページ側から自動で切り替えることはできないため、LINE内で開くと画面上部に案内を出します。Androidは「標準ブラウザで開く」ボタンで切り替えられます。iPhoneは、LINE画面右下の「…」/共有ボタンから「Safariで開く」を選ぶか、「URLをコピー」でSafariに貼り付けてください。LINEのメッセージにURLを送るときは、末尾に `?openExternalBrowser=1` を付けると、そのリンクをタップした時点でデフォルトブラウザで開きます（例: `https://mayuminakano.github.io/Recruting_Soccer/?openExternalBrowser=1`）。
- 注意: `localStorage` はブラウザ・端末ごとに別です。ブラウザのサイトデータを消すと失われるため、**定期的にJSONバックアップ**を取ってください。

## 🚀 起動方法

### 方法 1: ダブルクリックで直接起動（Windows）
`start_app.bat` をダブルクリックするだけで、デフォルトのブラウザでアプリが開きます。

### 方法 2: ブラウザで開く
`us-soccer-recruit-app/index.html` を任意のブラウザ（Chrome, Edge, Safari等）にドラッグ＆ドロップまたはダブルクリックで開きます。
